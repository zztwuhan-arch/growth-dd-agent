# Growth DD Agent — 成长型企业财务尽调原型

将“企业阶段 → 财务指标 → 风险假设 → 补充材料 → 证据核验 → 人工复核”串成可操作的工作流。来自个人财务尽调项目设计，本次补成可运行 Python / Streamlit 原型。它是有明确步骤的工作流，不是自主投资决策系统。

## 开始使用

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
streamlit run app.py
```

默认 demo 无需密钥：载入合成数据，计算指标，生成补充材料清单，检索相关原文。demo 核验状态始终为 `insufficient`，不能将关键词命中当作事实证实。填入自己的 `OPENAI_API_KEY` 后选择 openai，可获得结构化支持度判断和逐字引用；模型通过 `OPENAI_MODEL` 配置。API 费用由你的账户承担，相关材料片段会发送给模型。

## 已实现

- **阶段差异**：early 关注现金支撑期，growth 关注应收与收入增速差、现金与利润匹配，mature 更关注现金转化；各阶段同时检查客户集中和毛利变化。
- **可审计计算**：全部比率由 Python 计算。零/非正分母不产生无穷值，明确显示数据缺口。输入固定两个完整可比年度，同币种、同单位；百分比以 0–1 填写。
- **假设驱动核查**：每个异常附有可能解释、具体材料请求和检索关键词；绝不由异常直接认定造假。
- **材料检索与核验**：UTF-8 TXT/Markdown，按行关键词排序，返回文件 ID、行号和原文。不是 embedding/vector RAG，可能漏掉同义表达、否定上下文或未命中材料。
- **结构化输出校验**：supported / partially_supported / contradicted / insufficient；引用必须匹配检索片段，无证据结论降级；全部保留人工复核要求。
- **人工复核和导出**：记录处理意见、理由，下载 JSON。材料变化后旧报告失效，避免错配。

## 演示顺序

1. 运行默认成长型企业样本，查看应收、现金流、集中度、毛利四个假设。
2. 查看每项材料清单，修改补充材料，再运行，观察检索片段变化。
3. 如有 API key 切换 openai，查看支持度及引用；结合银行流水、合同等独立证据由人复核。
4. 记录结论并下载，说明哪些假设仍未验证。

## 测试与真实边界

```bash
python3 -m unittest -v
python3 evaluate.py
```

`evaluation-cases.json` 是人工编制的 12 组规则回归样例（不是独立盲测集），覆盖各阶段、零分母、正常对照和异常组合。评测计算假设 ID 的 micro precision/recall；这是规则实现一致性指标，不能称为识别真实财务风险的准确率。OpenAI 实调在本次交付中未验证；测试使用模拟响应验证引用校验与降级机制。

阈值均为可解释的**产品原型假设**，不是会计准则、审计标准或行业统一标准。未实现 Excel/PDF/OCR 自动提取、外部银行核验、行业基准库、向量数据库、用户权限或长期存储；不提供审计意见、造假结论或投资建议。
